# 个人品牌策略师技能说明（中文版）V1

## 1. 这是什么
这是一个通用 Skill，名字叫：

`personal-brand-strategist`

它不是为某一个具体行业、某一个具体人、某一种具体平台写的，而是一个通用的“个人品牌梳理方法 Skill”。

它的作用是帮助别人把自己零散的经历、优势、目标、渠道、内容和表达方式，梳理成一个清晰可用的个人品牌系统。

## 3. 这个 Skill 适合什么时候用
这个 Skill 适合在下面这些场景中使用：

- 帮别人从零开始梳理个人品牌
- 帮别人把已经很零散的经历、项目、平台、身份重新整理清楚
- 帮别人明确品牌定位、目标人群、差异化、内容结构
- 帮别人搭建内容生态、渠道角色、表达系统
- 当一个人的品牌已经“看起来很多，但说不清楚自己是谁”时
- 当一个人的品牌“看起来很厉害，但不像他本人”时
- 当一个人的品牌“方向很多，但没有总线”时

## 4. 这个 Skill 的核心能力
这个 Skill 做的不是直接写文案，而是先做上层梳理。

它主要负责：

- 梳理品牌定位
- 梳理目标用户
- 梳理差异化
- 区分“现在已经成立的身份”和“未来想长出来的方向”
- 梳理主品牌、子品牌、副号、项目、渠道之间的关系
- 把品牌逻辑转化为后续可以继续使用的表达系统

## 5. 用一句话总结
这个 Skill 的本质，就是：

`帮助一个人把“我好像做了很多事，但说不清楚我是谁”这件事，慢慢梳理成一个清晰、真实、可复用的品牌系统。`
