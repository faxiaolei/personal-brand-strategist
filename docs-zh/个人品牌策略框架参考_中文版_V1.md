# 个人品牌策略框架参考（中文版）V1

## 1. 这份参考文件是干什么的
这份文档是 `personal-brand-strategist` Skill 里面的参考框架。

它的作用是：

当一个人的品牌很乱、很虚、很散、很多身份打架的时候，用这份框架去重新诊断。

## 2. 核心诊断维度

### 2.1 真实证据
先看哪些东西是已经成立的：

- 角色与身份
- 项目与经历
- 真实做过的事情
- 数据、里程碑、行动轨迹
- 已经建立的信任

### 2.2 目标人群
要分清楚：

- 现在最重要的人是谁
- 第二层的人是谁
- 哪些人现在还不应该成为主叙事中心

### 2.3 真实问题
不要写成：

- 想成长
- 想做品牌
- 想扩大影响力

要写成更具体的 tension，比如：

- 有很多经历，但别人记不住我是谁
- 做了很多内容，但平台彼此割裂
- 有真实成绩，但不知道怎么说出来
- 有多个方向，但不知道该合并还是拆开

### 2.4 差异化
差异化必须同时满足三件事：

- 有证据
- 跟目标人群相关
- 不只是“我很努力”“我很真诚”“我很有热情”这种泛能力

### 2.5 阶段感
这个框架最强调的一点，就是必须区分：

- 现在已经成立的
- 现在正在形成的
- 未来想长出来的

## 3. 常见错误

### 3.1 为了谦虚，把真实成绩全抹掉
这会让品牌失去可信度。

### 3.2 为了好看，把未来方向写成现在身份
这会让品牌失真。

### 3.3 让所有平台都做同一件事
这会让内容生态失去结构。

### 3.4 只会写形容词，不会写问题
这会让品牌空。

### 3.5 只会写想法，不会写证据
这会让品牌飘。

## 4. 用一句话总结
这份框架的本质，就是：

`把一个人的经历、目标、平台、身份和未来方向，重新拆开，再重新搭回一个既真实、又能长期生长的品牌系统。`
