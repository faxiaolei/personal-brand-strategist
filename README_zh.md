# 个人品牌策略师

`Personal Brand Strategist` 是一个可复用的 Codex Skill，用来帮助不同的人梳理自己的个人品牌，包括定位、受众、差异化、内容生态和对外表达系统。

它是通用型的，不绑定某个具体行业、某个平台，也不只适用于某一种创作者身份。

## 这个 Skill 是做什么的

这个 Skill 的作用，是把一个人零散的经历、能力、目标、内容渠道和公开形象，整理成一套可以长期使用的品牌框架。

它尤其适合下面这些情况：

- 做过很多事情，但很难一句话说清自己是谁
- 有多个身份、多个平台，但整体表达比较分散
- 公开表达容易显得包装感过强、空泛或不一致
- 还没理清品牌逻辑，就急着写内容、做网站、做视觉
- 希望产出可复用的成果，比如品牌母框架、内容生态分工、对外表达手册等

## 英文 Skill 文件

真正用于 Codex 调用和复用的 Skill 主体放在 `skill-en/` 目录下，包括：

- `skill-en/SKILL.md`
- `skill-en/agents/openai.yaml`
- `skill-en/references/framework.md`

如果别人未来要把这个 Skill 安装到 Codex 里，主要看的是这部分内容。

## 中文说明文件

`docs-zh/` 里的中文文件是给人阅读的说明资料，主要用于帮助中文读者理解：

- 这个 Skill 是什么
- 适合在什么情况下使用
- 它会帮助产出哪些成果
- 它背后的品牌梳理逻辑是什么

这部分不是 Skill 运行的必需文件，但很适合你在 GitHub 上一起公开。

## 建议的 GitHub 发布方式

如果你要把它传到 GitHub，建议这样理解：

- `skill-en/`：正式的 Skill 实现文件
- `docs-zh/`：中文解释材料
- `README.md`：英文主页说明
- `README_zh.md`：中文主页说明

这样上传以后，中英文就可以同时保留，而且结构也很清楚。

## 说明

- 这个 Skill 是通用版本，不绑定某一个人的个人品牌
- 它优先解决的是“先把策略理清”，不是直接替代后续执行
- 它会区分“当前真实状态”“当前对外价值”和“未来成长方向”，避免把人写得失真或过度包装
