# Personal Brand Strategy Framework

## Core diagnostic dimensions

Use these dimensions when the brand still feels scattered or vague.

### 1. Evidence

List what is already true:

- Role and credentials
- Projects and outputs
- Repeated environments or field exposure
- Real numbers, milestones, or track record
- Existing audience trust

### 2. Audience

Define:

- Primary audience now
- Secondary audience later
- Who should not be centered yet

### 3. Problem

Clarify the real tension the audience feels now.

Avoid abstract problems like “needs growth” or “wants a brand.” Prefer concrete tensions such as:

- does not know how to start
- has fragmented channels
- is over-served by big players but under-served in practice
- has proof but no clear story

### 4. Difference

Explain why this person is different in a way that is:

- evidence-based
- audience-relevant
- hard to confuse with generic competence

### 5. Stage

Always split:

- What is already true now
- What is being built now
- What is only a future aspiration

## Common deliverables

### Brand framework

Use when the person needs the high-level strategic logic:

- identity
- audience
- problem
- proof
- direction

### Content ecosystem framework

Use when the person already has or plans multiple channels, accounts, or assets and needs role clarity.

### External expression handbook

Use when the strategy is set and the person now needs consistent introductions, bios, and talking points.

### Relationship brief

Use when the person has a main brand and one or more side brands, sub-accounts, or adjacent lines that need to be related without confusion.

## Common mistakes to avoid

- Overcorrecting away real achievements in the name of “humility”
- Treating aspirations as current identity
- Making every platform do everything
- Hiding the core audience behind broad language
- Using labels without proof
- Writing for aesthetics before strategic clarity

## Useful pressure tests

Ask whether a draft answer can survive these questions:

- Why this person, specifically?
- Why this audience, specifically?
- Why now?
- What proof makes this believable?
- What should be said now versus later?
- What would make this feel like over-packaging?
